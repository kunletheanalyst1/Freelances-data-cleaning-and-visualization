# Freelances-data-cleaning-and-visualization
This repository contains 1,000 freelancer profiles from around the world which is  designed to reflect realistic variability using excel.

## Project Overview

This project focuses on cleaning, transforming, and analyzing a freelance marketplace dataset containing information about freelancers, their skills, experience, ratings, hourly rates, languages, countries, and work status.

## Dataset

The dataset contains 1,000 freelancer records with fields including:

 Freelancer ID
 Name
 Sex
 Age
 Country
 Language
 Primary Skill
 Years of Experience
 Experience Bucket
 Rating
 Hourly Rate (USD)
 Status
 Customer Satisfaction

## Data Cleaning

The project involved:

 Cleaning freelancer names
 Standardizing gender values
 Cleaning and standardizing country and language data
 Creating experience categories
 Cleaning hourly-rate data
 Handling missing values
 Creating calculated fields for analysis
 Preparing the dataset for reporting and visualization

# Analysis

The analysis explored:

 Freelancer ratings by primary skill
 Distribution of years of experience
 Freelancer skills
 Languages spoken
 Countries represented
 Freelancer work status
 Hourly-rate information
 Customer satisfaction
